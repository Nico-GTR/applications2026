# Alternance 2026 Applications — Dashboard

A tracking dashboard for my 2026 apprenticeship search (Data / AI): **270 applications** sent to **78 companies**, from the first email to the interviews landed — and the apprenticeship I ultimately accepted, at **Nokia**.

No framework, no build step: a static HTML/CSS/JS page, fed by data pre-computed from a personal CSV export.

![light / dark theme](https://img.shields.io/badge/theme-light%20%2F%20dark-7c8cff)
![no build step](https://img.shields.io/badge/build-none-34d399)

## Overview

- **Conversion pipeline** — funnel from application → 1st interview → 2nd interview → offer
- **Final outcome** — where it all led
- **Activity over time** — weekly series + cumulative total, GitHub-style activity calendar
- **Response times** — bucketed distribution, mean/median
- **Top companies** & **interview conversion rate** per company
- **Top 10 largest companies targeted** — ranked by real global headcount (external, hand-curated data), not by application volume
- **Targeted role themes** (Data Scientist, ML, Generative AI, etc.), extracted by keyword
- **Interactive table** — search and filter by status
- Light / dark theme, fully responsive

## Tech stack

- **Frontend** — vanilla HTML/CSS/JS + [Chart.js](https://www.chartjs.org/) (via CDN), nothing to install
- **Data prep** — Python 3 (standard library only)

## Project structure

```
dashboard.html        the dashboard itself (structure, style, display logic)
dashboard_data.js      aggregated data, generated by prepare_data.py (included, ready to use)
prepare_data.py         reads the raw CSV, cleans/normalizes it, computes aggregates, writes dashboard_data.js
```

## Run locally

No server needed: just open `dashboard.html` in a browser. The already-generated `dashboard_data.js` is included in the repo.

## Regenerate the data

The raw CSV is **not** versioned (it contains personal data). To regenerate `dashboard_data.js` from your own export:

1. Place a CSV export named `maestro_candidatures_alternance_2026_enrichi.csv` at the repo root, with at least the columns `entreprise`, `poste`, `statut`, `date_candidature`, `date_dans_colonne_actuelle`, `historique_json`, `jai_le_job`.
2. Run:
   ```
   python prepare_data.py
   ```
3. Reload `dashboard.html`.

The script automatically merges company name variants (e.g. subsidiaries, typos), reconstructs the funnel from the action history, and computes KPIs, response times, role themes, etc.

Two pieces of information don't come from the CSV and are set by hand in `prepare_data.py`: the company whose offer was accepted (`FINAL_OUTCOME_COMPANY`), and the approximate global headcounts of the largest companies targeted (`COMPANY_HEADCOUNT`, public sources, 2025).

## Privacy

The source CSV (`*.csv`) is excluded from the repo via `.gitignore`: it may contain columns or notes more detailed than what's actually displayed. Only the already-aggregated data in `dashboard_data.js` is published — company names are intentionally kept as-is.
